🎲 四顆不講武德的骰子

我給妳四顆公平的六面骰子，讓妳先選。然後千彰再選一顆，跟妳比誰擲得大。

聽起來很有紳士風度？其實這是一個陷阱。無論妳先挑哪顆，我都能挑出一顆有 2/3 機率贏妳的骰子。 😏

四顆骰子每一面出現的機率都相同；特殊的只是各面的數字。

第一步：請選一顆

這裡沒有「運氣比較好」的骰子。請大膽選，讓千彰當一次不太厚道的對手。

擲骰結果有隨機波動；長期勝率才會接近理論值。

第三步：揭穿詭計

這四顆骰子構成一個循環：A 贏 B → B 贏 C → C 贏 D → D 贏 A。每一個箭頭的勝率都是 24/36＝2/3。

如果「A 比 B 強」且「B 比 C 強」，直覺會以為 A 也比 C 強。但這裡的「強」指的是單次對擲的勝率超過一半，它不必遵守大小比較的遞移律。這叫做非遞移性（nontransitivity）。

綠色：千彰的骰子贏；紅色：妳的骰子贏。每格代表兩顆骰子各取一個面，共36種等可能結果。

四組對決為什麼都是 2/3？

A 勝 B：A 有四面是4，B 永遠是3，所以 4/6。

B 勝 C：C 有四面是2，B 永遠是3，所以 4/6。

C 勝 D：C 擲到6（2/6）一定贏；擲到2（4/6）且 D 擲到1（3/6）也贏，合計 2/6＋(4/6×3/6)＝2/3。

D 勝 A：D 擲到5（3/6）一定贏；擲到1（3/6）且 A 擲到0（2/6）也贏，合計 3/6＋(3/6×2/6)＝2/3。

補充：這不代表每一顆骰子對所有其他骰子都比較差。只有上述循環中的指定對手有 2/3 優勢。遊戲設計的關鍵，是讓後選者依對方的選擇挑剋星。

數學原型：統計學家 Bradley Efron 的非遞移骰子。參考 Plus Maths｜Curious dice 與 Math Detours｜Efron Dice。網頁與互動程式由千彰製作，無外部套件，離線可玩。
